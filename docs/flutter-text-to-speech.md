# Flutter Text To Speech On Device

For developers searching for **Flutter text to speech**, **Flutter TTS**, or **offline text to speech for Flutter**, this repository demonstrates on-device TTS as part of a complete mobile voice stack.

The example app includes:

- selectable voice models
- multiple quality options
- TTS playback inside the same voice pipeline
- pause/resume coordination with speech recognition
- a manual TTS test mode

Many Flutter text-to-speech integrations work for basic playback but become unstable when combined with [wake-word detection](https://davoice.io/wake-word) or speech recognition. This repository is useful because it shows how TTS can live inside a coordinated end-to-end voice flow on iOS and Android.
