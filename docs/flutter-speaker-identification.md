# [Flutter Speaker Identification And Speaker Verification](https://davoice.io/speaker-recognition)

If you are looking for [**Flutter speaker identification**](https://davoice.io/speaker-recognition) or [**Flutter speaker verification**](https://davoice.io/speaker-recognition), this repository demonstrates an on-device approach for iOS and Android.

In the example app, users can:

- create a speaker signature
- reuse a saved speaker signature
- redo speaker onboarding
- skip speaker verification when it is not needed

This allows voice flows such as:

- only continue when the onboarded speaker is detected
- personalize behavior for a known speaker
- protect voice actions behind speaker verification
- combine speaker gating with wake word and speech to text

Unlike many fragmented mobile voice stacks, this solution is designed to work as part of a full Flutter voice pipeline together with wake word detection, speech recognition, and text to speech.
